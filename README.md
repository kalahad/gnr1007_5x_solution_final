# GNR1007 Learning Game Series

ชุดเกมบทเรียนอินเทอร์แอคทีฟ 11 เกม สำหรับวิชา **GNR1007 การโปรแกรมคอมพิวเตอร์สำหรับวิศวกร**
คณะวิศวกรรมศาสตร์ มหาวิทยาลัยรามคำแหง — เล่นได้ทันทีบนเบราว์เซอร์มือถือ ไม่ต้องติดตั้งแอป

**เข้าเล่น:** https://kalahad.github.io/gnr1007-learning-games/

---

## ภาพรวม

โปรเจกต์นี้พัฒนาขึ้นเพื่อแก้ปัญหาการประเมินผลแบบท่องจำในวิชาโปรแกรมมิ่งพื้นฐาน โดยออกแบบให้ทุกข้อคำถามต้องอ่านสิ่งเร้าจริง (โค้ด C ที่คอมไพล์ได้จริง ตาราง หรือสถานการณ์) แล้ววิเคราะห์ ไม่ใช่ตอบจากความจำล้วน พร้อมกลไกเกมที่กระตุ้นให้ผู้เรียนอยากเล่นซ้ำจนครบทุกด่าน และใช้เตรียมตัวสอบ กว ด้านการเขียนโปรแกรมคอมพิวเตอร์

## รายชื่อเกมทั้ง 11 เกม

| เกม | ชื่อ | เนื้อหา | บทที่ |
|---|---|---|---|
| 1 | CPU City | Memory Hierarchy · Compiler/Interpreter · Network Classification | 1–2 |
| 2 | Memory Vault | Data Type Sizing · Overflow Mechanics · Casting | 3 |
| 3 | Operator Arena | Operator Precedence · Prefix/Postfix · Modulo | 4 |
| 4 | Logic Labyrinth | if / else if / else · switch-case · break | 5 |
| 5 | Loop Factory | for · while · do-while · infinite loop | 5 |
| 6 | Trace Detective | Trace table · ++x vs x++ · loop+modulo · nested loop | 5 |
| 7 | Circuit Blueprint | สัญลักษณ์ผังงาน (Flowchart) มาตรฐาน | 10 |
| 8 | Pit Crew | พารามิเตอร์ · return · pass by value · local/global | 6 |
| 9 | Lap Timer | ดัชนีอาร์เรย์ · การวนซ้ำ · out of bounds | 7a |
| 10 | Championship Final | ทบทวนรวมทุกบท | 1–7a, 10 |
| 11 | Final Corner | ทดสอบก่อนสอบจริง 15 ข้อ: อาร์เรย์ 2 มิติ · ลูปซ้อน · ไฟล์ r/w/a · OOP · Stack/Queue · Bubble Sort | 7b, 8, 9, 11 |

## คุณสมบัติหลัก

- **CLIMB MODE — แตะอย่างเดียว** ออกแบบสำหรับหน้าจอมือถือ กดด้วยนิ้วโป้งข้างเดียวได้ทั้งเกม
- **คลังข้อสอบ 36 ข้อต่อเกม** (เขตละ 12 ข้อ) ทุกข้อมีสิ่งเร้าที่ต้องอ่านจริง
- **ระบบดาว 6 ดวง** — ตอบถูก 1 ข้อ = 1 ดาว (เกม 10 เต็ม 7 ดาว)
- **ส่งออกคะแนนเป็น CSV** พร้อมรหัสนักศึกษา สำหรับอาจารย์เก็บผลการเรียนรู้
- **เรดาร์สรุปผลด้วย Chart.js** พร้อมฉบับ SVG สำรองเมื่อโหลด CDN ไม่สำเร็จ
- ทุกโค้ด C ในคำถามผ่านการคอมไพล์รันจริงด้วย gcc เทียบกับเฉลยแล้ว

## เทคโนโลยีที่ใช้

HTML/CSS/JavaScript แบบไฟล์เดียวจบ (single-file) ไม่ต้องมีขั้นตอน build ใช้ Chart.js ผ่าน cdnjs และฟอนต์จาก Google Fonts
เก็บสถานะเกมด้วย `sessionStorage` · ตัวตนผู้เรียนเก็บใน `sessionStorage` (ปิดเบราว์เซอร์แล้วหาย เหมาะกับเครื่องห้องแล็บที่ใช้ร่วมกัน) · ผลคะแนนรายเกมเก็บใน `localStorage` แยกตามรหัสนักศึกษา

## โครงสร้างไฟล์

```
index.html                  หน้าแรก / ลงทะเบียน / แผนที่ผจญภัย 11 ด่าน
game1_cpu_city.html         ... game11_final_corner.html
tools/gnr_core/             ชั้นปรับปรุงร่วม (CSS + JS) และสคริปต์ติดตั้งลงทุกเกม
generate_qr.py              สร้าง QR code ลิงก์เกม
```

ชื่อไฟล์เป็นภาษาอังกฤษล้วน ไม่มีเลขเวอร์ชันในชื่อไฟล์ (เพื่อให้ URL ที่แจกนักศึกษาไปแล้วคงที่ตลอดเทอม) เลขเวอร์ชันอยู่ใน footer ของแต่ละเกม (ต่อท้ายด้วย "UI v7.0")

## วิธีใช้งาน (สำหรับนักศึกษา)

เปิดลิงก์หรือสแกน QR code กรอกรหัสนักศึกษา 10 หลักและชื่อเล่น เลือกเกม แล้วเริ่มเล่นได้ทันที ไม่ต้องติดตั้งหรือสมัครสมาชิก

## วิธีอัปเดตเนื้อหา (สำหรับผู้ดูแล)

1. แก้เนื้อหาเกมในไฟล์ `gameN_*.html` ได้ตามปกติ
2. ถ้าแก้ส่วนร่วม (สี แถบสถานะ หน้าสรุปผล การลงทะเบียน) ให้แก้ที่ `tools/gnr_core/gnr_core.css` หรือ `gnr_core.js` แล้วรัน
   `python3 tools/gnr_core/apply_core.py .` สคริปต์จะแทนที่บล็อกระหว่าง `<!-- GNR-CORE:BEGIN -->` และ `<!-- GNR-CORE:END -->` ในทุกเกม (รันซ้ำได้ ไม่ซ้อนทับ)
3. อัปโหลดทับชื่อไฟล์เดิมใน repository ระบบ GitHub Pages จะอัปเดตภายในไม่กี่นาที โดย URL และ QR code เดิมยังใช้ได้

รหัสลับสำหรับผู้ไม่มีรหัสนักศึกษากำหนดไว้ที่ตัวแปร `SECRET` ใน `index.html` และ `tools/gnr_core/gnr_core.js` (เปลี่ยนแล้วรันขั้นตอนที่ 2)
