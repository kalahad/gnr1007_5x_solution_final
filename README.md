# GNR1007 Civil Lab: โครงงาน Final 5 เรื่อง

ชุดเครื่องมือประกอบโครงงาน Final ตอนที่ 2 ของวิชา **GNR1007 การโปรแกรมคอมพิวเตอร์สำหรับวิศวกร** คณะวิศวกรรมศาสตร์ มหาวิทยาลัยรามคำแหง ภาคเรียนที่ 1/2569 ผู้สอน ผศ.ดร.กุลวลัญช์ วรุณสิน

ทุกหน้าเป็นไฟล์ HTML เดี่ยว เปิดได้ทันทีบนเบราว์เซอร์คอมพิวเตอร์และมือถือ ไม่ต้องติดตั้งโปรแกรม

## โครงงานทั้ง 5 เรื่อง

| Lab | ชื่อ | ข้อมูลในโปรแกรม | แนวคิดหลัก |
|---|---|---|---|
| 1 | สะพานนี้ยังไหวไหม (Bridge Sag Check) | `defl[7]`, `span` | หารจำนวนเต็ม L/800, Type Casting, if-else if จากรุนแรงลงมา |
| 2 | ก้อนปูนสอบตก (Concrete Cube Judge) | `ksc[6]`, `fc` | ฟังก์ชันตัดสิน, ค่าขอบ >=, ค่าเฉลี่ยต้อง cast |
| 3 | เหล็กเส้นไม่เหลือเศษ (Rebar Cut Optimizer) | `len[5]`, `qty[5]`, `bar` | / กับ %, ปัดขึ้นด้วยจำนวนเต็ม, switch-case |
| 4 | ด่านชั่งพิทักษ์สะพาน (Weigh Station Guard) | `w[8]`, `limit` | แยกตันและกิโลกรัมด้วย / และ %, ร้อยละที่เกิน |
| 5 | นักพยากรณ์หน้าไซต์ (Pour Day Forecaster) | `rain[7]`, `start` | วนชื่อวันด้วย %, switch ซ้อน, ตัวนับ |

## วิธีใช้ตัวตรวจโครงงาน (สำหรับนักศึกษา)

1. เปิด `civil_lab_checker.html` กรอกรหัสนักศึกษา 10 หลัก เลือก Lab ของกลุ่ม แล้วกด **รับข้อมูลส่วนตัว** ระบบจะให้ข้อมูล 2-3 บรรทัดที่ไม่ซ้ำกับเพื่อน (กรอกรหัสเดิมได้ข้อมูลชุดเดิมทุกครั้ง)
2. แทนบรรทัดข้อมูลเหล่านั้นในฟังก์ชัน `main` ของโค้ด (เปลี่ยนเฉพาะตัวเลข ห้ามเปลี่ยนชื่อตัวแปรหรือรูปแบบ `printf`) แล้วคอมไพล์เป็นไฟล์ .exe
3. ส่งผลลัพธ์ได้ 3 วิธี
   - **อัปโหลดไฟล์ผลลัพธ์ (แนะนำ):** เปิด Command Prompt ในโฟลเดอร์ของไฟล์ .exe แล้วพิมพ์ `lab1.exe > result.txt` จากนั้นอัปโหลด `result.txt` (อ่านภาษาไทยได้ทั้ง UTF-8 และ ANSI)
   - **วางผลลัพธ์:** คัดลอกข้อความจากหน้าต่างผลลัพธ์มาวาง (ถ้าภาษาไทยเพี้ยน ระบบตรวจได้เฉพาะตัวเลข)
   - **วางโค้ด .c:** ระบบรันโค้ดในเบราว์เซอร์แล้วตรวจให้
4. ระบบบอกว่าบรรทัดไหนยังไม่ถูกและควรทบทวนเรื่องใด **โดยไม่บอกค่าที่ถูก** แก้จนขึ้นสถานะ **ผ่าน** แล้วจับภาพหน้าจอ **การ์ดผลตรวจ** ส่งอาจารย์

หมายเหตุ: เบราว์เซอร์รันไฟล์ .exe โดยตรงไม่ได้ จึงต้องส่งเป็นไฟล์ผลลัพธ์หรือโค้ดแทน ถ้าหน้าเว็บขึ้นกรอบสีแดงว่าสคริปต์ไม่ทำงาน ให้เปิดไฟล์ด้วย Google Chrome หรือ Microsoft Edge

## สำหรับอาจารย์

- การ์ดผลตรวจมี **รหัสยืนยัน 7 ตัว** ที่คำนวณจากรหัสนักศึกษา Lab คะแนน เวลา และวิธีส่ง ตรวจได้ที่ส่วน "สำหรับอาจารย์: ตรวจรหัสยืนยันจากภาพหน้าจอ" ท้ายหน้า ซึ่งแสดงข้อมูลส่วนตัวของนักศึกษาคนนั้นด้วย เพื่อใช้เทียบกับโค้ดที่ส่ง
- รหัสยืนยันเป็นการป้องกันการแก้ตัวเลขในภาพระดับเบื้องต้น และตัวตรวจยืนยันได้ว่าผลลัพธ์ถูก แต่ยืนยันไม่ได้ว่านักศึกษาเขียนโค้ดเอง ควรเสริมด้วยการถามหรือสุ่มดูโค้ด

## ความถูกต้องของตัวตรวจ

- ผลเฉลยคำนวณด้วยตัวแปลภาษา C ย่อ (MiniC) ชุดเดียวกับหน้า Civil Lab ซึ่งตรวจเทียบกับ gcc 13.3 แล้วตรงกันครบ 1,650 ชุดข้อมูล
- ข้อมูลส่วนตัวทุกชุดมีค่าขอบที่ตั้งใจไว้ (เช่น ร้อยละ 100 พอดี, กำลังอัดเท่ากับ f'c, น้ำหนักเท่ากับพิกัด, ฝน 10/35/90 mm) และตัดชุดที่ผลขึ้นกับความละเอียดของ float กับ double ออก นักศึกษาจึงไม่ถูกตัดสินผิดเพราะเลือกชนิดข้อมูลทศนิยมต่างกัน
- ทดสอบกับข้อผิดพลาดที่นักศึกษาพบบ่อย 16 แบบ (ลืม cast, > กับ >=, ไม่ปัดขึ้น, ลืม break, ชื่อวันเลื่อน ฯลฯ) คำใบ้ชี้ถูกเรื่อง
- ทดสอบบนคอมพิวเตอร์และมือถือ ทั้งโหมดสว่างและมืด
