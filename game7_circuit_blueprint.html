Zone 02 · Layout Room

สามท่าไหลของสนาม: Sequence · Selection · Iteration

ไม่ว่าสนามจะซับซ้อนแค่ไหน ทุกช่วงของสนามประกอบขึ้นจากสามท่านี้เท่านั้น และข้อสอบมักถามว่า ผังนี้ใช้ท่าไหน หรือ ลูกศรวนกลับไปที่กล่องใด

1) SEQUENCE — ทางตรง

ทำทีละกล่องจากบนลงล่าง ไม่มีทางแยก ไม่มีลูกศรวนกลับ

int a = 5; int b = a + 2; printf("%d", b);

2) SELECTION — โค้งที่ต้องเลือกไลน์

ขนมเปียกปูน 1 ลูก = if-else 1 ชุด ออกได้ 2 ทางเสมอ

if (t >= 25) printf("HOT"); else printf("COLD");

3) ITERATION — วนอีกหนึ่งรอบสนาม

ลูกศรวนกลับขึ้นไปหาขนมเปียกปูน คือ while หรือ for ในรูปผัง

for (i = 1; i <= 3; i++) printf("%d ", i);
สิ่งที่ต้องตรวจในผังผังที่ถูกต้องผังที่ผิด
ทางออกของ Decisionออกครบ 2 ทาง Yes และ Noออกทางเดียว หรือมี 3 ทาง
ทางออกของลูปมีเส้นที่พาออกจากวงเมื่อเงื่อนไขเป็นเท็จไม่มีทางออก = Infinite Loop
กล่องเปลี่ยนค่าตัวนับในวงมีกล่องที่ทำให้ค่าเข้าใกล้จุดหยุดลืมกล่อง i++ ลูปจึงไม่มีวันจบ

ห้องทดลอง: Pace Car — วางกล่องบนรางแล้วปล่อยรถ

สนามนี้มีหลุมทราย แตะเลือกกล่องจากคลังด้านล่างแล้วแตะช่องบนรางให้ครบทั้ง 3 ช่อง จากนั้นกดปล่อยรถ ถ้าลำดับผิด รถจะออกนอกโค้งที่ช่องแรกที่ผิด พร้อมบอกเหตุผล — ผ่านให้ครบทั้ง 2 รอบเพื่อรับ XP เต็ม
