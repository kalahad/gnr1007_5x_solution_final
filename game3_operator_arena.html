Arena 01 · The Precedence Ring

สังเวียนลำดับยศ: Operator Precedence

ตัวดำเนินการแต่ละตัวมี ยศ ไม่เท่ากัน ยศสูงกว่าได้คำนวณก่อนเสมอไม่ว่าจะเขียนอยู่ตรงไหนของนิพจน์ และเมื่อ ยศเท่ากัน ให้ไล่ตามทิศทางประจำระดับนั้น

ลำดับตัวดำเนินการทิศทางเมื่อยศเท่ากัน
1 (สูงสุด)( ) — วงเล็บ ทำก่อนเสมอในสุดก่อน
2++ -- ! — เพิ่ม ลด นิเสธขวาไปซ้าย
3* / % — คูณ หาร มอดูโลซ้ายไปขวา
4+ - — บวก ลบซ้ายไปขวา
5< <= > >= == != — เปรียบเทียบซ้ายไปขวา
6&& แล้วจึง || — ตรรกะ และ/หรือซ้ายไปขวา
7 (ต่ำสุด)= += -= — กำหนดค่า ทำท้ายสุดขวาไปซ้าย

ท่องสั้น ๆ ว่า วงเล็บ → คูณหารมอด → บวกลบ → เปรียบเทียบ → && → || → เท่ากับ แล้วลองใช้กับตัวอย่างมาตรฐานของบทนี้

int a = 7, b = 2, c = 3; int x; x = a + b * c % 4;
1b * c → 6   เหลือ a + 6 % 4
26 % 4 → 2   เหลือ a + 2
37 + 2 → 9
4x รับค่าท้ายสุด → 9
จุดหลอกข้อสอบ กว.ข้อเท็จจริง
ใน 8 % 3 * 2 ต้องทำ 3 * 2 ก่อนเพราะคูณสำคัญกว่ามอด* / % ศักดิ์เท่ากัน จึงไล่ซ้ายไปขวา ได้ (8 % 3) * 2 = 4 ไม่ใช่ 2
x = a + b เอาค่าเดิมของ x มาร่วมคำนวณด้วย= ยศต่ำสุด จึงคำนวณฝั่งขวาให้เสร็จก่อน แล้ว x ค่อยรับผลทีหลัง
if (x = 5) กับ if (x == 5) ให้ผลเหมือนกันหนึ่งขีดคือสั่งกำหนดค่า ทำให้เงื่อนไขเป็นจริงเสมอและค่าตัวแปรเปลี่ยน ส่วนสองขีดคือถามว่าเท่ากันไหม
2 + 3 > 4 ต้องเทียบ 3 > 4 ก่อนแล้วค่อยบวกบวกลบยศสูงกว่าเปรียบเทียบ จึงได้ (2 + 3) > 4 เป็นจริง = 1

Arena 02 · The Prefix/Postfix Twins

ฝาแฝดจอมหลอก: ++x กับ x++

ตัวดำเนินการเพิ่มค่า ++ และลดค่า -- วางได้สองตำแหน่ง ทั้งคู่ทำให้ตัวแปรลงเอยเท่ากัน ต่างกันเฉพาะ ค่าที่ถูกส่งออกไปใช้ในนิพจน์ตอนนั้น

int x = 5, y; y = ++x; int a = 5, b; b = a++;
กy = ++x → x เป็น 6 ก่อน แล้ว y รับ 6  ·  จบบรรทัด x = 6 , y = 6
ขb = a++ → b รับ 5 ก่อน แล้ว a ค่อยเป็น 6  ·  จบบรรทัด a = 6 , b = 5
Prefix ++xPostfix x++
ลำดับการทำงานเพิ่มค่าก่อน แล้วนำค่าใหม่ไปใช้ส่งค่าเดิมไปใช้ก่อน แล้วค่อยเพิ่ม
ตัวอย่างเมื่อ x = 5y = ++x → y = 6y = x++ → y = 5
ค่า x หลังจบบรรทัด66 (เท่ากันทั้งคู่)
จุดหลอกข้อสอบ กว.ข้อเท็จจริง
x++ ไม่ได้เพิ่มค่าจริง เพราะ y ได้ค่าเดิมเพิ่มจริงเสมอ เพียงแต่เพิ่มหลังส่งค่าเดิมออกไปแล้ว จบบรรทัด x เป็น 6 เท่ากับฝั่ง prefix
เปลี่ยน i++ เป็น ++i ในหัว for แล้วผลจะเปลี่ยนช่องที่สามของ for ทิ้งค่าที่ส่งออกมา ผลลัพธ์จึงเหมือนกันทุกประการ
--a * 2 ต้องคูณก่อนแล้วค่อยลด-- ยศสูงกว่า * จึงลดค่าก่อนเสมอ ได้ 4 * 2 = 8
++ ใช้กับตัวอักษรไม่ได้char คือจำนวนเต็มขนาดเล็ก c = 'A'; c++; จึงได้ 'B' ตามรหัส ASCII

Arena 03 · The Modulo Wheel & Logic Gate

วงล้อเศษ และประตูตรรกะ

% (มอดูโล) คือตัวดำเนินการ หาเศษจากการหารจำนวนเต็ม ไม่ใช่การหารเอาผลลัพธ์ เศษที่ได้จะน้อยกว่าตัวหารเสมอ จึงใช้เป็นเครื่องมือได้สารพัด

10 % 3 → 1 12 % 4 → 0 7 % 10 → 7
110 หาร 3 ได้ 3 เหลือเศษ 1
012 หาร 4 ลงตัว เศษจึงเป็น ศูนย์
7ตัวตั้งน้อยกว่าตัวหาร จึงได้ตัวตั้งคืนมาทั้งก้อน

จากนั้นนำไปใช้เป็นเครื่องมือได้ทันที

n % 2 == 0 n % 10 n % 7
·n % 2 == 0 ตรวจว่าเป็นเลขคู่หรือไม่
·n % 10 ดึงหลักหน่วยของ n ออกมา
·n % 7 จัดเวรวนเจ็ดวัน

ส่วน การประเมินแบบลัดวงจร (Short-circuit Evaluation) คือพฤติกรรมของ && และ || ที่ หยุดประเมินทันที เมื่อรู้ผลลัพธ์แน่นอนแล้ว โดยไม่แตะฝั่งขวาเลย

ตัวดำเนินการหยุดประเมินเมื่อเพราะ
&&ฝั่งซ้ายเป็น เท็จผลรวมเป็นเท็จแน่นอนแล้ว ไม่ว่าฝั่งขวาจะเป็นอะไร
||ฝั่งซ้ายเป็น จริงผลรวมเป็นจริงแน่นอนแล้ว ไม่ว่าฝั่งขวาจะเป็นอะไร
จุดหลอกข้อสอบ กว.ข้อเท็จจริง
% ใช้กับ float ได้ถ้าค่าลงตัวใช้ไม่ได้เลย gcc ฟ้อง invalid operands to binary % ตั้งแต่ขั้นแปล
เศษของเลขลบเป็นบวกเสมอภาษา C ตัดเข้าหาศูนย์ เศษจึงมีเครื่องหมายตามตัวตั้ง เช่น -7 % 3 ได้ -1
ฝั่งขวาของ && ถูกประเมินเสมอถ้าซ้ายเป็นเท็จ ขวาจะไม่ถูกแตะเลย จึงใช้กันหารด้วยศูนย์ได้
ผลของ ! เป็นค่าเดิมที่กลับเครื่องหมายให้ผลเป็น 0 หรือ 1 เท่านั้น !5 ได้ 0 และ !0 ได้ 1
