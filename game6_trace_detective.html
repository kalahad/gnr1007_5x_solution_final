Case 01 · The Evidence Table

คดีที่ 1: ตารางหลักฐาน — โปรแกรมนี้พิมพ์อะไร

นักสืบเก่งไม่ได้เดาเก่ง แต่ จดหลักฐานเก่ง คดีของเราคือคำถามว่า "โปรแกรมนี้พิมพ์อะไร" หลักฐานคือค่าตัวแปรทุกบรรทัด และเครื่องมือคือตารางทดค่า

  1. ห้ามทดในหัว — โค้ดเกิน 3 บรรทัดต้องตีตาราง ความจำคนแพ้กระดาษเสมอ
  2. หนึ่งคอลัมน์ต่อหนึ่งตัวแปร — บวกคอลัมน์ "พิมพ์อะไร" ไว้ขวาสุดเสมอ
  3. ไล่ตามลำดับการทำงานจริง — ไม่ใช่ตามลำดับบรรทัด ลูปวนกลับ เงื่อนไขกระโดดข้าม
  4. ตอบจากตาราง ไม่ตอบจากความรู้สึก — อ่านคำตอบจากคอลัมน์ผลลัพธ์เท่านั้น

ห้องทดลอง: เดินหลักฐานทีละบรรทัด

กด "เดินหนึ่งก้าว" เพื่อไล่ทีละรอบ หรือ "รันจนจบคดี" เพื่อดูรวดเดียว — ต้องปิดคดีให้ได้เพื่อรับ XP เต็ม

Case 02 · The Twin Suspects

คดีที่ 2: ฝาแฝด ++x และ x++

Prefix (++x)Postfix (x++)
ลำดับการทำงานเพิ่มค่าก่อน แล้วส่งค่าใหม่เข้านิพจน์ส่งค่าเดิมเข้านิพจน์ก่อน แล้วค่อยเพิ่ม
ตัวอย่าง x = 5y = ++x; → y = 6, x = 6z = x++; → z = 5, x = 6
ค่า x หลังบรรทัดจบเพิ่มขึ้น 1 เท่ากันทั้งคู่ — ต่างกันเฉพาะค่าที่ถูกส่งเข้านิพจน์

จำง่าย ๆ: Pre = เพิ่มก่อนใช้ · Post = ใช้ก่อนเพิ่ม

ห้องทดลอง: สอบปากคำฝาแฝด

เลือกสำนวนคดี แล้วเดินทีละบรรทัดเพื่อดูว่าค่าใดถูกส่งไปให้ตัวแปรใด — ปิดให้ครบทั้ง 2 สำนวนเพื่อรับ XP เต็ม
