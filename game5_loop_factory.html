Line 01 · The Conveyor

สายพานนับรอบ: for loop

หัวลูป for มี 3 ส่วนคั่นด้วย ; — เริ่มต้น ; เงื่อนไขวนต่อ ; ท้ายรอบ ลำดับการทำงานคือ เริ่มต้นครั้งเดียว → ตรวจเงื่อนไข → ทำในบล็อก → ทำท้ายรอบ → กลับไปตรวจใหม่

for (int i = 0; i < 5; i++) // 5 รอบ: 0 1 2 3 4 for (int i = 1; i <= 5; i++) // 5 รอบ: 1 2 3 4 5 for (int i = 0; i < 10; i += 2) // 5 รอบ: 0 2 4 6 8
รูปแบบสูตรนับรอบค่า i หลังจบลูป
i = 0; i < N; i++N รอบN
i = 1; i <= N; i++N รอบN + 1
i = 0; i < N; i += kปัดขึ้นของ N/k รอบค่าแรกที่ทำให้เงื่อนไขเท็จ

จุดหลอก กว.: < กับ <= ต่างกัน 1 รอบ เสมอ และค่า i หลังจบลูปคือค่าที่ทำให้เงื่อนไข เท็จ ไม่ใช่ค่าสุดท้ายที่พิมพ์

ห้องทดลอง: เดินสายพาน (Conveyor Simulator)

เลือกหัวลูปแล้วดูกล่องไหลออกมาทีละรอบ พร้อมนับรอบและค่า i หลังจบลูป — ลองให้ครบทั้ง 4 แบบเพื่อรับ XP เต็ม

Before Line 02

กำลังจะเข้าสู่: ห้องเครื่องสองตัว (while vs do-while)

ทักษะที่จะได้: while & do-while

รู้ว่า while อาจทำงาน 0 รอบ ส่วน do-while การันตีอย่างน้อย 1 รอบเสมอ และเลือกใช้ให้เหมาะกับงาน

Line 02 · Two Machines

ห้องเครื่องสองตัว: เช็กก่อนทำ หรือ ทำก่อนเช็ก

whiledo-while
ลำดับการทำงานตรวจเงื่อนไขก่อน แล้วจึงทำทำก่อน 1 รอบ แล้วจึงตรวจเงื่อนไข
จำนวนรอบต่ำสุด0 รอบ (ถ้าเงื่อนไขเท็จตั้งแต่แรก)1 รอบ เสมอ
เหมาะกับงานวนตามเงื่อนไขที่ยังไม่รู้จำนวนรอบงานที่ต้องทำอย่างน้อยหนึ่งครั้ง เช่น รับค่าจากผู้ใช้แล้วค่อยตรวจ
int i = 10; while (i < 5) { printf("A"); } // ไม่ทำงานเลย — 0 รอบ int j = 10; do { printf("B"); } while (j < 5); // ทำงาน 1 ครั้ง!

ห้องทดลอง: สตาร์ทเครื่องสองตัวพร้อมกัน

เลือกค่าเริ่มต้นแล้วกดสตาร์ท เครื่องทั้งสองใช้เงื่อนไขเดียวกันคือ i < 5 — ลองให้ครบทั้ง 4 กรณีเพื่อรับ XP เต็ม

ยังไม่ได้เลือกเครื่อง

สรุปกฎที่ต้องจำ

while เงื่อนไขเท็จตั้งแต่แรก = 0 รอบ
do-while เงื่อนไขเท็จตั้งแต่แรก = 1 รอบ
ข้อสอบชอบให้เงื่อนไขเป็นเท็จตั้งแต่ต้นเพื่อวัดจุดนี้โดยเฉพาะ

Before Line 03

กำลังจะเข้าสู่: ห้องควบคุมความร้อน (Overheat Room)

ทักษะที่จะได้: จับผิด Infinite Loop

ใช้เช็กลิสต์ 3 ข้อจับลูปที่วนไม่รู้จบ: ตัวนับเปลี่ยนไหม เงื่อนไขมีวันเท็จไหม และมี ; แอบปิดลูปไหม

Line 03 · Overheat Room

ห้องควบคุมความร้อน: ตรวจจับลูปที่วนไม่รู้จบ

ลูปที่วนไม่รู้จบทำให้เครื่องจักรร้อนจนไหม้ — ตรวจ 3 ข้อนี้ทุกครั้งก่อนตอบ

เช็กลิสต์คำถามที่ต้องถามตัวเอง
1. ตัวนับมีคำสั่งเปลี่ยนค่าตัวนับในลูปหรือไม่ (i++, i--, i += k)
2. ทิศทางค่าที่เปลี่ยนไปวิ่ง เข้าหา เงื่อนไขหยุดหรือวิ่งหนีออกไป
3. semicolonมี ; ปิดหัวลูปก่อนถึงบล็อกหรือไม่ (ลูปตัวเปล่า)

ห้องทดลอง: เครื่องตรวจความร้อน (Overheat Detector)

อ่านโค้ดแต่ละหน่วยแล้วตัดสินว่า "ปกติ" หรือ "วนไม่รู้จบ" — ตรวจให้ครบทั้ง 6 หน่วยเพื่อรับ XP เต็ม

int i = 0;
while (i < 5) {
    printf("%d", i);
}
for (int j = 10; j > 0; j++) {
    printf("%d", j);
}
int i = 0;
while (i < 5);
{
    i++;
}
for (int i = 0; i < 5; i++) {
    printf("%d", i);
}
int k = 0;
do {
    k += 2;
} while (k < 10);
int n = 1;
while (n != 10) {
    n += 4;
}
