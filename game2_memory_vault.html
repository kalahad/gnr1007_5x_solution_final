Vault 01 · The Sizing Vault

ห้องนิรภัยขนาดต่าง: char / int / float / double

ตัวแปรคือกล่องที่มี ขนาดตายตัวตั้งแต่ตอนประกาศ ไม่ยืดหดตามค่าที่ใส่ เลือกกล่องเล็กไปข้อมูลจะล้น เลือกใหญ่ไปก็เปลืองหน่วยความจำ

ชนิดข้อมูลขนาดช่วงค่าเปรียบเหมือน
char1 byte-128 ถึง 127กล่องไม้ขีด
unsigned char1 byte0 ถึง 255กล่องไม้ขีดที่ไม่เก็บเครื่องหมาย
int4 byte-2,147,483,648 ถึง 2,147,483,647กล่องพัสดุ
float4 byte±3.4×1038 (ละเอียด ~7 หลัก)กล่องพัสดุที่เก็บทศนิยม
double8 byte±1.7×10308 (ละเอียด ~15 หลัก)ตู้คอนเทนเนอร์

กฎที่ต้องรู้คู่กับตารางนี้ เพราะเป็นที่มาของทุกข้อในห้องนี้

char c = 'A'; int n = 100; sizeof(c) → 1 /* ตามชนิดของตัวแปร */ sizeof(n) → 4 sizeof(c + n) → 4 /* char ถูกยกเป็น int ก่อนคำนวณเสมอ */
จุดหลอกข้อสอบ กว.ข้อเท็จจริง
char เก็บได้ถึง 255จริงเฉพาะ unsigned char ส่วน char ธรรมดามีเครื่องหมาย เก็บได้แค่ -128 ถึง 127
float ต้องใหญ่กว่า int เพราะเก็บทศนิยมได้ทั้งคู่ใช้ 4 byte เท่ากัน ต่างกันแค่วิธีตีความบิตข้างใน
float เก็บเลข 9 หลักได้ครบfloat ละเอียดเพียง ~7 หลัก เลข 123456789 จะเพี้ยนเป็น 123456792 เงียบ ๆ
Age กับ age คือตัวแปรเดียวกันภาษา C แยกตัวพิมพ์เล็ก-ใหญ่ จึงเป็นคนละตัวแปรกันโดยสิ้นเชิง

Vault 02 · The Overflow Gauge Room

ห้องมิเตอร์ล้น: Overflow

ชนิดข้อมูลทุกแบบมีเพดานค่าสูงสุดที่เก็บได้ ถ้าคำนวณแล้วค่าเกินเพดานนั้น ตัวเลขจะ วนกลับ (wrap around) ไปเริ่มใหม่อีกฝั่งของช่วงค่า ไม่ใช่หยุด ไม่ใช่ error และไม่มีการแจ้งเตือนตอนรัน

ชนิดข้อมูลช่วงค่าสูงสุด + 1ต่ำสุด − 1
signed char-128 ถึง 127127 → -128-128 → 127
unsigned char0 ถึง 255255 → 00 → 255
unsigned int0 ถึง 4,294,967,295วนกลับเป็น 00 → 4294967295

วิธีคิดเร็วเมื่อค่าเกินเพดาน: เอา 256 ลบออกจากค่าที่เกิน สำหรับกล่องขนาด 1 ไบต์

char x = 100; x = x * 2; /* คำนวณใน int ได้ 200 ก่อน */ /* แล้วยัดลง char : 200 - 256 = -56 */ printf("%d", x); → -56
จุดหลอกข้อสอบ กว.ข้อเท็จจริง
127 + 1 ได้ 128เป็นไปไม่ได้ เพราะ 128 เกินเพดานของ char — คำตอบคือ -128
ค่าเกินเพดานจะถูกตัดให้เหลือค่าสูงสุดไม่ตัด แต่ วนรอบ ไปอีกฝั่งของช่วงค่า
Overflow ทำให้โปรแกรมพังโปรแกรมทำงานต่อจนจบตามปกติ ค่าเพี้ยนไปเงียบ ๆ ซึ่งอันตรายกว่า
unsigned n >= 0 จะเป็นเท็จเมื่อ n ติดลบunsigned ไม่มีค่าติดลบ เงื่อนไขนี้จึงเป็นจริงเสมอ และมักกลายเป็นลูปไม่รู้จบ

Vault 03 · Foundry & Twin Vault

เตาหลอมแปลงร่าง และห้องนิรภัยคู่แฝด

การแปลงชนิดข้อมูล (Type Casting) มีสองแบบ Implicit คอมไพเลอร์แปลงให้เองเมื่อสองฝั่งของนิพจน์คนละชนิด และ Explicit ที่ผู้เขียนสั่งเองด้วยวงเล็บ เช่น (float)a

int a = 7, b = 2; float c1 = a / b; → 3.0 /* หารก่อนในโลก int แล้วค่อยแปลง */ float c2 = (float) a / b; → 3.5 /* แปลงก่อน แล้วค่อยหาร */ int d = 3.9; → 3 /* ตัดทศนิยมทิ้ง ไม่ปัดเศษ */ int e = -3.9; → -3 /* ตัดเข้าหาศูนย์ */

ส่วนห้องนิรภัยคู่แฝดคือเรื่องของ บิตชุดเดียวกันที่อ่านได้สองค่า เพราะ signed เผื่อบิตซ้ายสุดไว้บอกเครื่องหมาย

บิตในหน่วยความจำอ่านแบบ signed charอ่านแบบ unsigned char
0111 1111127127
1000 0000-128128
1111 1111-1255
จุดหลอกข้อสอบ กว.ข้อเท็จจริง
7 / 2 ได้ 3.5int หาร int ได้ 3 เสมอ ต่อให้เอาผลไปใส่ float ก็สายไปแล้ว
ประกาศตัวแปรปลายทางเป็น float ก็พอชนิดปลายทางไม่ย้อนกลับไปเปลี่ยนวิธีคำนวณ ต้อง cast ก่อนหาร
int d = 3.9 ได้ 4ได้ 3 เพราะ "ตัด" ไม่ใช่ "ปัด" — อยากปัดต้องบวก 0.5 เองก่อน
