Zone 01 · Lap Board

บอร์ดเวลาต่อรอบ: index เริ่มนับที่ศูนย์เสมอ

อาร์เรย์คือ ตารางเวลาต่อรอบ ที่จองช่องติดกันไว้ล่วงหน้า ช่องแรกของบอร์ดคือ lap[0] ไม่ใช่ lap[1] ดังนั้นเวลาของ รอบที่ k จึงอยู่ที่ lap[k-1] เสมอ และเมื่อบอร์ดมี n ช่อง ช่องสุดท้ายคือ lap[n-1]

สิ่งที่ต้องจำความหมายบนหอจับเวลา
int lap[5];จองช่องติดกัน 5 ช่อง ขนาดตายตัวตั้งแต่ประกาศ เพิ่มทีหลังไม่ได้บอร์ดที่ทำป้ายไว้ 5 ช่องพอดี
lap[0]สมาชิกตัวแรกของอาร์เรย์เวลาของรอบที่ 1
lap[n-1]สมาชิกตัวสุดท้ายเมื่อมี n ช่องเวลาของรอบสุดท้าย
lap[k-1]สมาชิกลำดับที่ k ตามที่คนนับเวลาของรอบที่ k
lap[n]Out of Bounds ไม่มีช่องนี้จริงขอดูเวลาของรอบที่ยังไม่ได้วิ่ง
sizeof(lap)/sizeof(lap[0])จำนวนช่องทั้งหมดของอาร์เรย์นับป้ายบนบอร์ดว่ามีกี่ช่อง

จุดหลอกสิ่งที่มักตอบผิดข้อเท็จจริง
ถามถึง "ตัวที่ 3"เลือก a[3] ตามตัวเลขในโจทย์ตัวที่ 3 คือ a[2] — ตัวที่ k อยู่ที่ a[k-1]
int a[5] แล้วใช้ a[5]คิดว่ามีช่องที่ 5 ให้ใช้index สูงสุดคือ 4 ส่วน a[5] คือ Out of Bounds ได้ค่าที่ไม่แน่นอน และ คอมไพเลอร์ไม่ฟ้อง error
กำหนดค่าทั้งก้อนหลังประกาศเขียน a = {1,2,3}; ในบรรทัดถัดมาทำได้เฉพาะ ตอนประกาศ เท่านั้น เขียนแบบนี้ทีหลังคือ compile error
กำหนดค่าเริ่มต้นไม่ครบช่องคิดว่าช่องที่เหลือเป็นค่าขยะint p[5] = {4, 8}; ช่องที่เหลือถูกเติมเป็น 0 ให้อัตโนมัติ

ห้องไล่รอบ: อาร์เรย์คู่กับลูป

คู่หูประจำบทนี้คือ for (i = 0; i < n; i++) ซึ่งเดินครบทุกช่องพอดีโดยไม่หลุดขอบ เพราะรอบสุดท้ายที่เงื่อนไขยังเป็นจริงคือ i = n-1 ซึ่งตรงกับช่องสุดท้ายพอดี

รูปแบบที่ต้องอ่านออกโค้ดสิ่งที่ได้
รวมทุกช่องs = 0; for (i=0;i<n;i++) s = s + a[i];ผลรวมของทั้งอาร์เรย์
หาค่ามากที่สุดmax = a[0]; for (i=1;i<n;i++) if (a[i] > max) max = a[i];รอบที่ช้าที่สุด
หาค่าน้อยที่สุดm = a[0]; for (i=1;i<n;i++) if (a[i] < m) m = a[i];Fastest Lap
