Before Chamber 01

กำลังจะเข้าสู่: ห้องประตูสามชั้น (The Three Gates)

ทักษะที่จะได้: if / else if / else

อ่านเงื่อนไขจากบนลงล่าง รู้ว่า "เจอจริงตัวแรกทำแล้วข้ามที่เหลือทั้งหมด" และวางลำดับเงื่อนไขให้ถูกต้อง

Chamber 01 · The Three Gates

ห้องประตูสามชั้น: if / else if / else

ในเขาวงกตนี้ ผู้ผจญภัยต้องเดินผ่านประตูเรียงกันจากบนลงล่าง ประตูแรกที่เงื่อนไขเป็นจริงจะเปิดให้ผ่าน แล้วประตูที่เหลือจะถูกปิดตายทันที นี่คือหัวใจของ if-else ที่ข้อสอบ กว. ชอบหลอก

int score = 75; if (score >= 80) printf("A"); else if (score >= 70) printf("B"); // ประตูนี้เปิด else if (score >= 60) printf("C"); // ไม่ถูกตรวจแล้ว else printf("F");
สิ่งที่นักศึกษาคิดสิ่งที่คอมพิวเตอร์ทำจริง
75 ผ่านทั้งเกณฑ์ 70 และ 60 น่าจะพิมพ์ B และ Cพิมพ์เฉพาะ B เพราะเจอจริงตัวแรกแล้วออกจากโครงสร้างทันที
เขียนเงื่อนไขสลับลำดับก็ได้ผลเหมือนกันถ้าเอา score >= 60 ขึ้นก่อน ทุกคนที่ได้ 75 จะกลายเป็น C ทันที

ห้องทดลอง: เดินผ่านประตู (Gate Runner)

เลือกคะแนนแล้วดูว่าประตูไหนถูกตรวจ ประตูไหนถูกข้าม — ลองให้ครบทั้ง 4 ปุ่มเพื่อรับ XP เต็ม

พิมพ์ B

พิมพ์ C

พิมพ์ F

ทักษะที่จะได้: กับดัก if ที่ข้อสอบรัก

Dangling else, = กับ ==, semicolon เกิน และกฎ "ไม่ใช่ 0 คือจริง" ของภาษา C

Chamber 02 · The Shadow Traps

ห้องกับดักเงาซ้อน: 4 กับดักที่ทำให้เสียคะแนนมากที่สุด

กับดักสิ่งที่ตาเห็นสิ่งที่เกิดขึ้นจริง
Dangling elseย่อหน้าทำให้คิดว่า else คู่กับ if ตัวนอกelse จับคู่กับ if ที่ใกล้ที่สุด เสมอ คอมไพเลอร์ไม่สนใจย่อหน้า
= แทน ==คิดว่ากำลังเปรียบเทียบเป็นการ กำหนดค่า แล้วใช้ค่านั้นตัดสินจริง/เท็จ
semicolon เกินif (x > 0); ดูเหมือนปกติตัว ; ปิด if ทันที บล็อกข้างล่างจึงทำงาน เสมอ
ค่าความจริงของตัวเลขคิดว่าต้องเป็น true/false เท่านั้นใน C 0 = เท็จ ส่วนเลขอื่นทุกตัวรวมทั้งค่าลบ = จริง

ห้องทดลอง: เครื่องตรวจจับกับดัก (Trap Detector)

เลือกกับดักด้านบนเพื่อดูโค้ด

Before Chamber 03

กำลังจะเข้าสู่: โถงหลายแพร่ง (The Switchboard Hall)

ทักษะที่จะได้: switch-case & break

รู้ว่า switch เทียบค่าเท่ากันเท่านั้น และเห็นด้วยตาว่าการไม่ใส่ break ทำให้ผลลัพธ์ "ไหลทะลุ" อย่างไร

Chamber 03 · The Switchboard Hall

โถงหลายแพร่ง: switch-case และประตูกั้นชื่อ break

switch คือทางแยกหลายแพร่งที่ เทียบค่าเท่ากันเท่านั้น ใช้ได้กับ int และ char ใช้ช่วงค่าแบบ score >= 80 ไม่ได้ และที่สำคัญที่สุดคือ break ทำหน้าที่เป็นประตูกั้น ถ้าไม่มี โปรแกรมจะไหลลง case ถัดไปเรื่อย ๆ

switch (day) { case 1: printf("Mon "); break; case 2: printf("Tue "); break; case 3: printf("Wed "); break; default: printf("Other"); }

ห้องทดลอง: สวิตช์บอร์ด (Switchboard)

เลือกค่าของ day แล้วสลับสวิตช์ break เพื่อดูว่าผลลัพธ์ที่พิมพ์เปลี่ยนไปอย่างไร — ทดลองให้ครบ 6 รูปแบบเพื่อรับ XP เต็ม
สวิตช์ break ควบคุม ทุก case พร้อมกัน และโค้ดด้านบนจะเปลี่ยนตามสวิตช์เสมอ ผลลัพธ์ที่ได้จึงตรงกับโค้ดที่เห็น

ผลลัพธ์จะปรากฏที่นี่
ยังไม่ได้กดสวิตช์
